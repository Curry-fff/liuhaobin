# 报时鸟 演示脚本（李忠林 · 测试 / 演示）

对应角色：演示。本脚本用于答辩/验收时的现场走查，按顺序执行即可覆盖核心功能。

## 一、开场（30 秒）

介绍：报时鸟是桌面语音助手，核心是"说一句就记、到点主动提醒"。打开墨刀原型首页。

## 二、核心演示（按顺序）

1. 前台对话页输入"我叫刘浩彬，请你记住" → 显示"记住了，你叫刘浩彬"，出现"工具: memory.remember ✓"。
2. 输入"我是谁" → 显示"你叫刘浩彬"。
3. 输入"提醒我周五 22:00 交软工作业" → 显示"已记下提醒"，日程页出现该提醒。
4. 切到日程页 → 点"＋新增提醒" → 填内容、选"每天" → 保存 → 列表新增一条周期提醒。
5. 点"模拟到点" → 弹出"周五 22:00 该交软工作业啦"，点"已完成"关闭。
6. 切到设置页 → 切换大模型开关 → 保存。
7. 进入后台管理 → 仪表盘看统计 → 提醒管理搜索/完成一条 → 工具管理停用 weather → 设备管理绑定一台设备。

## 三、收尾（20 秒）

总结三个亮点：主动提醒、免提语音、可接硬件。给出 GitHub 仓库与文档链接。

## 四、备选兜底

若现场无网：演示第 1、2、4 步（不依赖网络）；大模型接口不可用时说明"离线规则模式兜底"。
