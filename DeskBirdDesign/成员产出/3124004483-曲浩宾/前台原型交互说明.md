# 前台原型交互说明（曲浩宾 · 前端）

对应角色：前端。本文件定义前台应用四个视图的页面结构、交互与规则，与墨刀原型、`prototype/index.html` 一致。

## 页面清单

| 页面 | 组成 | 关键交互 |
| --- | --- | --- |
| 对话页 | 左侧导航 + 顶栏 + 聊天区 + 输入区 | 发送消息；按住说话；工具调用显示 |
| 日程页 | 提醒列表 + 新增按钮 | 新增 / 完成 / 删除；弹窗表单 |
| 课表页 | 星期 × 节次表格 | 查看本周课程 |
| 设置页 | 音色、渠道、开关、记忆 | 保存设置；删除记忆 |
| 到点浮层 | 提醒气泡 | 已完成 / 10 分钟后再提醒 |

## 交互规则

1. 对话意图优先级：记忆（"我叫X"）> 身份询问（"我是谁"）> 提醒（"提醒我/别忘了/记得"）> 待办 > 工具查询（时间/天气/计算/课表）。
2. 语音识别失败自动降级为文字输入；识别中按钮呈"录音态"高亮。
3. 新增提醒：内容必填，否则拒绝并提示；时间可选"一次性/每天/间隔 N 分钟"。
4. 到点提醒气泡为置顶浮层，两个按钮均关闭气泡；"已完成"同时把对应提醒置灰。
5. 主题：主色 #FF8C42、深橙 #D96A1F、浅底 #FFF4EC、文字 #5A3A22，圆角 10–14px。
